# 👋 Sobre mim

Sou estudante da área de tecnologia, com foco em **desenvolvimento Front-End** e interesse em construir interfaces modernas, intuitivas e com uma boa experiência para o usuário.

<br>

Atualmente curso **Engenharia de Software pela UNIASSELVI**, na modalidade **EAD**, buscando desenvolver uma base sólida em lógica de programação, desenvolvimento de sistemas e boas práticas de engenharia de software.

<br>

Também sou aluno do **CentroWEG**, onde tenho a oportunidade de vivenciar o ambiente profissional da tecnologia, aplicando conhecimentos técnicos e evoluindo minhas habilidades através de experiências práticas.

<br>

Tenho grande interesse pelo desenvolvimento Front-End, explorando tecnologias como **HTML, CSS e JavaScript**, além de buscar constantemente novos conhecimentos em frameworks, bibliotecas e ferramentas que contribuam para a criação de aplicações web eficientes e agradáveis para os usuários.
